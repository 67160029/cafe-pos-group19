# เอกสารตั้งทีมและแผนการพัฒนาระบบร้านกาแฟ (Team Charter)

# องค์ประกอบ 6 ส่วน
 
**People** - คนที่เกี่ยวข้องกับระบบ เช่น ลูกค้า พนักงาน เจ้าของร้าน บาริสต้า
 
**Process** - ขั้นตอนการทำงาน เช่น รับออเดอร์ → ชำระเงิน → ทำกาแฟ → ส่งสินค้า
 
**Data** - ข้อมูลที่ระบบเก็บ เช่น เมนู ราคา รายการสั่งซื้อ ลูกค้า ยอดขาย
 
**Hardware** - อุปกรณ์ที่ใช้ เช่น คอมพิวเตอร์ เครื่อง POS เครื่องพิมพ์ใบเสร็จ Tablet
 
**Software** - โปรแกรมที่ใช้ เช่น ระบบ POS ระบบจัดการร้าน ฐานข้อมูล Windows
 
**Network** - การเชื่อมต่อ เช่น Wi-Fi อินเทอร์เน็ต Router Cloud Database


# แบบจำลอง SDLC ที่เลือกใช้
 
**เลือกใช้:** แบบจำลอง Agile
    
**เหตุผลที่เลือก:**

1.สามารถปรับปรุงระบบได้ตลอด หากร้านต้องการเพิ่มเมนูใหม่หรือฟีเจอร์ใหม่ เช่น ระบบสมาชิกหรือโปรโมชั่น

2.พัฒนาและส่งมอบระบบเป็นส่วน ๆ ได้ เช่น ทำระบบรับออเดอร์ก่อน แล้วค่อยเพิ่มระบบสต๊อกสินค้า

3.เจ้าของร้านสามารถทดลองใช้งานและให้ข้อเสนอแนะได้ทุกช่วง ทำให้แก้ไขข้อผิดพลาดได้รวดเร็ว
