# AI Disclosure — WK12 Usability Testing

## เครื่องมือ AI ที่ใช้

- OpenAI Codex

## งานที่ AI ช่วย

- ตรวจ repo และ wireframe เดิมเพื่อระบุว่าขาด UI ที่ใช้งานจริงสำหรับ POS
- ร่างและ implement หน้า POS ที่เชื่อม API เดิม เพื่อเตรียมระบบสำหรับการทดสอบกับคนจริง
- ร่าง task ตั้งต้นและจัดรูปแบบไฟล์ `wk12-usability-testing.md`

## งานที่ AI ไม่ได้ทำ

- ไม่ได้ทำ task ในฐานะผู้ทดสอบแทนคน
- ไม่ได้สร้างบทพูด think-aloud หรือบันทึกการสังเกตสมมติ
- ไม่ได้จัดอันดับ usability issue จากข้อมูลที่ไม่มี session จริง

## สิ่งที่สมาชิกกลุ่มต้องตรวจสอบ

- ตรวจโค้ด UI และทดสอบกับฐานข้อมูล/ข้อมูลสาขาที่ใช้จริงก่อนเริ่ม session
- ตรวจ task ให้ตรงกับชื่อเมนูและ branch_id ที่มีอยู่ และแก้ถ้อยคำที่อาจชี้นำก่อนอ่านให้ผู้ทดสอบ
- บันทึกคำพูด พฤติกรรม เวลา และปัญหาจาก session จริง พร้อมระบุการใช้ AI เพิ่มเติมหากนำ AI มาช่วยสรุป transcript หรือแก้รายงาน
- ตรวจการคำนวณ/การบันทึกออเดอร์และยืนยันว่า UI ใช้ได้กับ schema และ API ของกลุ่ม
