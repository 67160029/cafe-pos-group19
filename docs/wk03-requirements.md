# Requirements Document

## 1. บทนำ (Introduction)

### ภาพรวมระบบ

ระบบ **POS And Smart Inventory System** สำหรับร้านกาแฟ ใช้ช่วยรับออเดอร์ คิดเงิน จัดการสมาชิก และตัดสต็อกวัตถุดิบอัตโนมัติ

### วัตถุประสงค์

1. ลดเวลาในการรับออเดอร์และคิดเงิน
2. ลดความผิดพลาดในการจดออเดอร์
3. ตัดสต็อกและแจ้งเตือนวัตถุดิบใกล้หมดอัตโนมัติ

### ผู้มีส่วนได้ส่วนเสีย

* เจ้าของร้าน
* พนักงานหน้าร้าน
* บาริสต้า
* ลูกค้าสมาชิก

---

# 2. ขอบเขตระบบ (Scope)

### In Scope

* รับออเดอร์ผ่านระบบ POS
* คิดเงินและออกใบเสร็จ
* ส่งออเดอร์ไปยังบาริสต้า
* ตัดสต็อกอัตโนมัติ
* ระบบสมาชิกและสะสมแต้ม
* รายงานยอดขาย

### Out of Scope

* ระบบบัญชีและภาษี
* ระบบสั่งซื้อวัตถุดิบอัตโนมัติ
* ระบบเดลิเวอรี
* ระบบเงินเดือนพนักงาน

---

# 3. Functional Requirements

**FR-01** ระบบต้องให้พนักงานเข้าสู่ระบบก่อนใช้งาน

**FR-02** ระบบต้องให้พนักงานเลือกเมนู ขนาด และท็อปปิ้งผ่านหน้าจอได้

**FR-03** ระบบต้องคำนวณราคารวม ภาษี และส่วนลดอัตโนมัติ

**FR-04** ระบบต้องรับชำระเงินและออกใบเสร็จได้

**FR-05** ระบบต้องส่งออเดอร์ไปยังหน้าจอบาริสต้าทันทีหลังชำระเงิน

**FR-06** ระบบต้องตัดสต็อกวัตถุดิบอัตโนมัติหลังการขาย

**FR-07** ระบบต้องค้นหาสมาชิกด้วยเบอร์โทรและบันทึกคะแนนสะสมได้

**FR-08** ระบบต้องแสดงรายงานยอดขายรายวัน รายเดือน และเมนูขายดี

---

# 4. Non-functional Requirements

**NFR-01** ระบบต้องตอบสนองภายใน **2 วินาที**

**NFR-02** ระบบต้องพร้อมใช้งานไม่น้อยกว่า **99%**

**NFR-03** ระบบต้องเข้ารหัสรหัสผ่านด้วย **bcrypt**

**NFR-04** ระบบต้องใช้งานได้บนคอมพิวเตอร์และแท็บเล็ตทั่วไป

---

# 5. Constraints

* พัฒนาระบบให้เสร็จภายใน **4 เดือน**
* งบประมาณไม่เกิน **200,000 บาท**
* ใช้งานผ่าน Web Application บนอุปกรณ์ทั่วไป

---

# 6. Interview Summary

**Q1:** ร้านมีปัญหาอะไร?
**A:** จดออเดอร์ผิดและคิดเงินช้า

**Q2:** อยากให้ระบบช่วยอะไร?
**A:** รับออเดอร์และคิดเงินอัตโนมัติ

**Q3:** ปัญหาสต็อกคืออะไร?
**A:** ของหมดแต่ไม่รู้ เพราะเช็กด้วยมือ

**Q4:** อยากให้ระบบสต็อกทำอะไร?
**A:** ตัดสต็อกและแจ้งเตือนของใกล้หมด

**Q5:** ต้องการระบบสมาชิกไหม?
**A:** ต้องการสะสมแต้มด้วยเบอร์โทร

**Q6:** อยากดูข้อมูลอะไร?
**A:** ยอดขายรายวัน รายเดือน และเมนูขายดี

**Q7:** มีข้อจำกัดอะไร?
**A:** งบประมาณไม่เกิน 200,000 บาท

**Q8:** อยากให้เสร็จเมื่อไร?
**A:** ภายใน 4 เดือน
