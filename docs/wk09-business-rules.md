# WK09 Workshop — Business Rules

1. หากจำนวนสินค้าที่ต้องการสั่งมากกว่าสต็อกคงเหลือ ระบบต้องปฏิเสธการสั่งซื้อ
2. เมื่อยืนยันออเดอร์สำเร็จ ระบบต้องบันทึก Order และ Order Item และตัดสต็อกตามจำนวนที่สั่ง
3. หากสต็อกเหลือน้อยกว่า 10 หน่วยหลังตัดสต็อก ระบบต้องตรวจพบและส่ง `lowStockMenuIds` กลับใน response พร้อม `console.warn`
4. ราคาสินค้าใน Order Item ต้องใช้ราคาจาก `menu_item.price` ในฐานข้อมูล ไม่รับ `unitPrice` จาก client
5. การจัดการเมนูทุก endpoint ต้องระบุ `branchId` และตรวจสอบ `menu_id` คู่กับ `branch_id` เพื่อป้องกัน IDOR
